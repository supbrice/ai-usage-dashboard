# AI Usage Dashboard

Local tracker for free / everyday AI platforms:

ChatGPT · Claude · Gemini · Grok · Perplexity · Microsoft Copilot · Cursor

## Run locally

1. Download `index.html`
2. Open it in Chrome / Edge / Firefox (double-click or drag into a browser window)
3. Log sessions. Data stays in **this browser** via `localStorage`

No server, no account, no install.

## Features

- Log minutes (and optional message count) per platform
- Purpose tags (coding, Azure lab, job hunt, learning, content, other)
- Today / 7-day / 30-day totals
- Per-platform bars (last 30 days)
- Optional weekly minute caps
- CSV export / import

## Notes

Vendor free tiers usually do **not** expose usage APIs. This dashboard is intentional manual logging so it stays accurate and private.
